# JSAPIscan

JavaScript API 端点发现工具。

本仓库用于发布 JSAPIscan 的编译版本和使用说明，源码不在此仓库公开。

## 下载

请前往 [Releases](https://github.com/ruisika/jsapiscan/releases) 下载对应平台的程序。

| 系统 | 架构 | 文件 |
| --- | --- | --- |
| Windows | x86_64 | `JSAPIscan_windows_amd64.exe` |
| Linux | x86_64 | `JSAPIscan_linux_amd64` |
| Linux | ARM64 | `JSAPIscan_linux_arm64` |
| macOS | Intel | `JSAPIscan_mac_x86_64` |
| macOS | Apple Silicon | `JSAPIscan_mac_arm64` |
